ИНСТРУКЦИЯ КАК ДОБАВЛЯТЬ В АНКИ

Если импортировать (apkg) то тип записи создастся сам, но можно сделать его вручную — 4 поля: слово, перевод, ассоциация и похожие. Потом при импорте выбрать разделитель (|) и этот тип записи.

Обратите внимание: Убедитесь в правильности импорта в полях ГДЕ ПРОВЕРЯТЬ (тип записи и колоды), иначе не все слова добавятся! По умолчанию там часто стоят неверные настройки.

Можно потом еще добавить звуки и картинки, подробный перевод и примеры на англ. Хорошие картинки должны удивлять или смешить и наглядно изображать предмет, глагол или ФА (фразовую ассоциацию) — от плохих картинок толку мало. Списки иногда меняются, так что форматируйте их здесь под свои нужды.

Приложение АНКИ-дроид

Преимущества и особенности

  • Сразу доступен импорт/экспорт без необходимости обязательной регистрации!
  • Возможность скачивать базы из общего хранилища.
  • Интервальное повторение.
  • Красивое HTML/CSS оформление карточек (много полей).

Рекомендуется вставить в стили карточки (через Редактировать -> Карточка -> Стили) следующие настройки для правильного отображения:

.card { font-size: 28px; }
a { color: darkblue; }
i { color: red; }
.hr1 { border-top: 1px solid #428bca; margin: 3px 0; }
.hr2 { border-top: 2px solid green; margin: 3px 0; }
.hr3 { border-top: 2px solid red; margin: 3px 0; }
  • Общая база в хранилище хаотична, много лишней информации.
  • Удалять выученные слова неудобно (через меню-исключить).
  • Свои медиафайлы вставлять долго и сложно, встроенной озвучки нет (можно настроить виджет Google Переводчика).
Приложение QuizLet

Преимущества и особенности

  • Встроенная озвучка английского и русского языков из коробки.
  • Удобный обмен колодами по ссылке или названию.
  • Нет прямого импорта-экспорта в мобильном приложении, обязательна регистрация на сайте.
  • Картинки только из коллекции приложения, мелкие.
  • Нет полноценного интервального повторения.
  • Хранилище колод скрыто — искать нужные наборы приходится вслепую.
Итог: Рекомендуем использовать Anki для ПК или AnkiDroid для Android. ФА (ассоциации) позволяют отлично тренировать воображение даже без картинок.
